三步开始

1

订阅

浏览下面的卡片，点击「订阅」。订阅保存在浏览器本地。

2

导出

点击「导出清单」下载 subscriptions.json，或复制同步命令。

3

同步

克隆仓库，把清单放进去，跑一条命令，全部装进你的 profile。

node scripts/dsh-subscribe.mjs sync --profile web
git 安装被 pnpm 拦截时：按 dsh CLI 打印的 allowBuilds 指引，在 profile 的 pnpm-workspace.yaml 里加对应包名，再重跑 sync 即可。
